# **About Adobe Director Lingo Decompiler**

# 

##### This tool is designed to inspect, decompile and extract the contents of Adobe Director files (.DCR, .DXR, .CCT, .CXT and Projector .EXE files).

##### 

##### A .DCR file is a D**irector Shockwave movie**, a published multimedia file created with **Macromedia Director**, later owned by Adobe. Director was widely used for interactive CD-ROMs, educational software, games, presentations, and multimedia content on the early web.

##### 

##### A published Director movie can contain many different types of resources, including graphics, sounds, animations, data, and Lingo scripts.

# 

# **Features**

# 

### **Opening files**

##### • Open Director movies and casts: .DCR, .DXR, .CCT and .CXT

##### • Open Projector executables (.EXE): the embedded Director files are detected and extracted next to the .EXE, and if there are several you choose which one to open

##### • Browse all cast members with type icons, and filter the list by library and by type

##### • Search for strings throughout the opened file using Edit > Find (with Previous / Next)

### **Lingo scripts**

##### • Extract and browse embedded Lingo scripts

##### • Decompile Lingo bytecode into readable source code

##### • Select and inspect individual scripts

### **Cast member viewers**

##### • **Bitmaps:** preview with zoom and pan, including alpha masks and custom palettes

##### • **Sounds:** playback with pitch control

##### • **Text and ByteArrays:** show the readable text

##### • **Shockwave 3D:** interactive 3D view of the whole world (see below)

##### • **Fonts:** short information about the embedded font

##### • **Shapes and Flash movies:** listed and inspectable like all other cast members

### **3D viewer**

##### • Built-in software renderer,

##### • Orbit with the left mouse button, pan with the middle or right button, zoom with the mouse wheel

##### • Click a model to select it, double-click a model in the view or in the scene list to focus the camera on it

##### • Scene list with all nodes, including show / hide for single models and Show all / Hide all

##### • Wireframe mode, Z-up mode, switchable scene lights, Reset view and Fit model

##### • Play, stop and rewind animations with a time slider and optional looping

### **Export**

##### • Export the selected cast member using File > Export Selected Cast Member (or Ctrl+S)

##### • Export many cast members at once using File > Export Cast Members: choose which types to export, an export folder, and optionally a subfolder for each type

##### • Scripts are exported as .ls, bitmaps as .png (or the original .jpg), sounds in their audio format, text and ByteArrays as .txt, Flash movies as .swf and shapes as .png

##### • Shockwave 3D worlds can be exported as FBX, W3D, or both, including their textures and keyframes

##### • The Xtra list (.x32 names and download URLs) can be exported as a text file

### **W3D / FBX Converter**

##### • Convert Shockwave 3D (.W3D) files to FBX and FBX files back to W3D

##### • Choose the up axis (Y-up or Z-up) of the target file

##### • W3D to FBX writes the textures next to the FBX file

##### • FBX to W3D embeds textures (the image files must be found next to the FBX)
